# Tic Tac Toe Game in C++

## Project Overview
This project is a console-based Tic Tac Toe game developed using C++. It allows two players to play against each other on a 3x3 game board.

## Features
- Two-player gameplay using X and O.
- Interactive 3x3 game board.
- Win detection for rows, columns, and diagonals.
- Draw detection when all positions are occupied.
- Input validation for invalid positions.
- Prevention of moves in occupied positions.
- Option to play again.

## Technologies Used
- C++
- GCC (MinGW)
- Visual Studio Code

## How to Compile and Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal in the project directory.
3. Compile the program:

   ```bash
   g++ main.cpp -o TicTacToe.exe
   ```

4. Run the game in PowerShell:

   ```powershell
   .\TicTacToe.exe
   ```

## How to Play
1. Player 1 uses X, and Player 2 uses O.
2. Enter a number from 1 to 9 to select a board position.
3. Players take turns until someone wins or the game ends in a draw.
4. Enter Y to play again or N to exit.

## Learning Outcomes
This project demonstrates the use of functions, arrays, loops, conditional statements, input validation, and basic game logic in C++.
